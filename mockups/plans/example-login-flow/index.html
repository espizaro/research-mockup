Pantalla de login con biometría

Reutiliza el patrón de la pantalla inicial con CTA primario y opción de Face ID.

Objetivo

Construir la pantalla de login con la biometría como acción secundaria destacada y el email/password como flujo alterno.

Archivos

  • src/features/auth/LoginScreen.tsx
  • src/features/auth/LoginScreen.module.css
  • src/core/i18n/en.json
  • src/core/i18n/es.json

Comandos

  • npm run typecheck
  • npm run lint
  • rg -n "biometric|faceId" src/features/auth

Verificación

  • El CTA primario es Continuar con email
  • Face ID aparece como botón secundario con icono correcto
  • Dark mode sin sombras ni bordes en tarjetas

Notas

La biometría nunca debe ser el único método: siempre deja el email/password visible.
